# NOVA Casino

Мобильное веб-казино на виртуальные фишки: слоты, рулетка, блекджек и покер с живыми игроками.
Аккаунты, лидерборд, профиль с историей ставок. Реальных денег нет.

## Запуск

```bash
npm install
npm run build   # собрать клиент
npm start       # сервер + клиент на http://localhost:3001
```

Для разработки — два процесса с автоперезагрузкой:

```bash
npm run dev:server   # API и WebSocket на :3001
npm run dev:client   # Vite на :5173, проксирует /api и /ws
```

Проверить покер в одиночку поможет тестовый соперник:

```bash
node server/tools/poker-bot.mjs poker:1 4
```

## Устройство

```
server/src
  index.js        HTTP API, раздача клиента, WebSocket
  db.js           SQLite: users, bets, poker_stacks
  auth.js         регистрация, вход, токены (scrypt + JWT)
  wallet.js       все операции с балансом и запись ставок
  hub.js          комнаты реального времени и рассылка состояния
  games/          slots, roulette, blackjack, poker, cards
client/src
  lib/            api, socket, состояние приложения
  pages/          экраны
  components/     общие элементы интерфейса
  styles.css      дизайн-токены и стили
```

Вся игровая логика и генерация случайных чисел (`crypto.randomInt`) — на сервере.
Клиент только отправляет действия и рисует состояние, которое прислал сервер, поэтому
подделать результат или баланс из браузера нельзя.

## Мультиплеер

| Игра | Комната | Как устроено |
| --- | --- | --- |
| Слоты | `slots` | общий зал: счётчик игроков и живая лента спинов |
| Рулетка | `roulette` | один стол, раунды по таймеру, ставки всех игроков видны |
| Блекджек | `bj:1…3` | до 5 игроков против дилера в одном раунде |
| Покер | `poker:1…3` | безлимитный холдем, 6 мест, побочные банки |

## Настройки окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт сервера | `3001` |
| `DATA_DIR` | папка с базой и секретом | `server/data` |
| `JWT_SECRET` | секрет подписи токенов | создаётся в `DATA_DIR` |
| `VITE_API_URL` | адрес сервера для клиента (при сборке) | тот же хост |

## Встраивание

- **GTA (CEF-браузер в MTA / RAGE / FiveM).** Откройте адрес сервера во встроенном браузере.
  Если страница грузится из ресурса игры, соберите клиент с `VITE_API_URL=https://ваш-сервер`.
  Вёрстка рассчитана на ширину от 360 px и на планшетный формат.
- **Телефон и бот.** Тот же адрес открывается как Telegram Mini App или обычная страница.

Что нужно добавить перед такой интеграцией:

1. Вход без пароля: эндпоинт, который выдаёт токен по подписи игрового сервера или по
   `initData` Telegram, вместо формы логина.
2. Связь баланса с игровой валютой: серверный API с ключом для пополнения и списания.
3. CORS для `VITE_API_URL`, если клиент и сервер на разных доменах, и HTTPS.

## Правила игр

- **Слоты:** 3×3, 5 линий, расчётный возврат около 94%.
- **Рулетка:** европейская, одно зеро; число 35:1, дюжины и колонки 2:1, равные шансы 1:1.
- **Блекджек:** 6 колод, дилер стоит на 17, блекджек 3:2, удвоение на двух картах; сплита и страховки нет.
- **Покер:** бай-ин 20–200 больших блайндов, 25 секунд на ход, два пропуска подряд — игрок встаёт.
