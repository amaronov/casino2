# NOVA Casino

Мобильное веб-казино на виртуальные фишки: слоты, рулетка, блекджек и покер с живыми игроками.
Аккаунты, лидерборд, профиль с историей ставок. Реальных денег нет.

- **Сайт:** https://amaronov.github.io/casino2/
- **Фронтенд:** React + Vite, публикуется на GitHub Pages при каждом пуше в `main`.
- **Бэкенд:** Supabase — Postgres, одна Edge Function (`api`) и Realtime.

## Как это устроено

```
client/                    интерфейс (React)
  src/config.js            адрес проекта Supabase и публичный ключ
  src/lib/api.js           вызовы Edge Function
  src/lib/socket.js        подписка на комнату: Realtime + опрос
supabase/
  migrations/              схема базы: players, bets, rooms
  functions/api/           вся серверная логика
    index.ts               операции API, транзакции, баланс
    auth.ts                логин/пароль (PBKDF2) и токены (HMAC)
    games/                 slots, roulette, blackjack, poker
tools/poker-bot.mjs        тестовый соперник для покера
```

Клиент не обращается к таблицам напрямую: они закрыты RLS без политик. Каждое действие —
это `POST` в функцию `api`, которая в одной транзакции блокирует строку комнаты, применяет
действие, меняет балансы и сохраняет состояние. Случайные числа берутся из `crypto` на сервере,
так что результат и баланс из браузера подделать нельзя.

Постоянного сервера нет, поэтому таймеры (ход в покере, раунд рулетки) хранятся в состоянии
комнаты как срок и исполняются при первом обращении любого клиента после этого срока.
Клиенты сами заглядывают в комнату в момент срока и раз в 10 секунд. Об изменениях остальные
узнают через Realtime-сигнал и запрашивают своё представление (со своими картами).

## Разработка

```bash
npm install
npm run dev        # интерфейс на http://localhost:5173, работает с боевым Supabase
```

Изменения бэкенда выкатываются через Supabase CLI (нужен `supabase login` и `supabase link`):

```bash
npm run deploy:db    # применить новые миграции
npm run deploy:api   # выкатить Edge Function
```

Функции нужен секрет `APP_JWT_SECRET` (подпись токенов игроков):
`supabase secrets set APP_JWT_SECRET=<случайная строка от 32 символов>`.
Локальные секреты лежат в `.env`, который не попадает в репозиторий.

## Ограничения

- Таймеры срабатывают с точностью до обращения клиента: обычно это доли секунды, но если
  за столом никого нет, раздача «замирает» до прихода первого игрока.
- Игрок, чей клиент молчит дольше минуты, автоматически встаёт из-за покерного стола.
- Боты в покере включаются переключателем «Игра с ботами» за столом (1–5 ботов, только для
  сидящих игроков). Стек бота — 100 больших блайндов, он не связан ни с чьим балансом: выигрыш
  у бота — это новые фишки в игре, проигрыш боту — сгоревшие. В лидерборд и историю боты
  не попадают и уходят вслед за последним человеком за столом.
- Каждое действие и каждый опрос — вызов Edge Function; на бесплатном тарифе Supabase
  их 500 000 в месяц.
- Ограничения частоты попыток входа нет.

## Встраивание

- **GTA (CEF-браузер в MTA / RAGE / FiveM).** Откройте адрес сайта во встроенном браузере.
- **Телефон и бот.** Тот же адрес открывается как Telegram Mini App или обычная страница.

Для полноценной интеграции понадобятся вход без пароля (операция в `api`, выдающая токен
по подписи игрового сервера или `initData` Telegram) и операция для связи баланса с игровой валютой.

## Правила игр

- **Слоты:** 3×3, 5 линий, расчётный возврат около 94%.
- **Рулетка:** европейская, одно зеро; число 35:1, дюжины и колонки 2:1, равные шансы 1:1.
- **Блекджек:** 6 колод, дилер стоит на 17, блекджек 3:2, удвоение на двух картах; сплита и страховки нет.
- **Покер:** безлимитный холдем, бай-ин 20–200 больших блайндов, 25 секунд на ход.
